## Interpretation

HGB126 and HGB169 are re-scored on the same 17,731 train OOF/outer rows, with identical keys, raw truth and grouped folds. The endpoint panel uses cycles floor(0.5, 0.7, 0.9 × lifetime), clamped to the first available cycle.

The warning table fixes threshold 30 or 40 cycles, persistence 1 and lead requirement 30 for both models. It is a sensitivity description; threshold 40 is not presented as a newly calibrated policy. The historical 94% calibrated169 readout remains a separate reference.

Recommendation for the report: use HGB169 as the main predictor candidate because it is better on the common trajectory and endpoint panels. Keep the warning policy separate: fixed threshold30 is less timely for HGB169, while threshold40 is slightly more timely with a small burden increase. This is not an unconditional whole-process improvement claim.

The smoothing analysis uses only train observations and a causal trailing mean30. First-difference SD reduction is a proxy for attenuation, not proof that C-MAPSS contains recoverable measurement noise. No parameter was fitted or selected, and no claim is made that smoothing improves RUL.

## Limits

- Bootstrap intervals condition on persisted predictions and omit refit, seed and model-selection uncertainty.
- HGB126 uses 126 rolling features; HGB169 uses 126 rolling + cycle + 42 history features. This is a feature-representation comparison, not an architecture-only comparison.
- The study is historically inspected. It is not a new blind independent confirmation.
- Complete train trajectories make false-alarm denominators structurally different from deployment data; warning burden and retractions are reported instead.
