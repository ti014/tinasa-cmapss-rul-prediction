# Archived presentation artifacts

Các file trong thư mục này là bản cũ hoặc bản trung gian được giữ để đối chiếu.
Chúng không phải output trình chiếu hiện hành.

- `decks/`: các deck cũ. `cmapss_fd001_presentation_18slides_20260928.pptx` là
  deck 18 slide dùng trước khi dựng lại cho bài nói 30 phút;
  `..._18slides_20260928_beamer.tex` và `.pdf` là nguồn và bản PDF Beamer tương
  ứng. Các file `before_*` và `transfer` là bản cũ hơn.
- `builders/`: script build/finalize của các phiên trước, gồm
  `build_academic_presentation.mjs` và `finalize_academic_presentation.mjs` của
  deck 18 slide. Hai script này ghi đường dẫn tới deck cũ và không còn dùng.
